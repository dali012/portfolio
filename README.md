# Med Ali Jerbi Portfolio

Personal portfolio for [dali012.me](https://dali012.me), built with Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, and Magic UI.

## Local Development

```bash
pnpm install
pnpm dev
```

## Static Build

```bash
pnpm build
```

The production output is generated in `out/` for Cloudflare Pages.

## Cloudflare Pages

- Build command: `pnpm build`
- Output directory: `out`
- Node.js: `20.9.0` or newer
